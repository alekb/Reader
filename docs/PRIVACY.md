Reader Quest ("the app") is made by [OWNER NAME] ("we"). It teaches children to read. A parent or guardian sets it up and manages any account.

## What the app collects

| Data | Where it is stored | Why |
|---|---|---|
| Child's first name or nickname (typed by the parent or child) | On the device; in our cloud backup if the parent signs in | To greet the child in the app |
| Learning progress: sounds and words practised, answers, stars, unlocked rewards | On the device; in the cloud backup if signed in | To choose the next lesson and show progress to the parent |
| Session history: date, time, length and accuracy of each session | On the device; in the cloud backup if signed in | Parent dashboard statistics |
| Parent's email address and password (password is never visible to us) | Google Firebase Authentication, only if the parent creates an account | To sign in and restore progress on another device |
| Voice recordings of letter sounds, **only if the parent chooses to record them** | On the device; in the cloud backup if signed in | To play the sounds in the parent's own voice |

The app does **not** collect location, contacts, photos, device identifiers for advertising, or any data from the child's microphone except when a parent presses Record in the parent-only settings. There are **no ads, no analytics and no tracking**, and nothing is sold or shared with third parties.

## Service providers

Cloud backup uses Google Firebase (Authentication and Cloud Firestore), operated by Google LLC, which stores the data on our behalf. See https://firebase.google.com/support/privacy.

## Children

The child does not need an account. Only a parent or guardian can create one, behind a parent check. We do not knowingly collect personal information from a child beyond the first name and learning data described above.

## Keeping and deleting data

- Data on the device stays until the app is uninstalled or the parent uses **Parents → Settings → Reset all progress**.
- Cloud data stays while the account exists.
- **Delete everything:** Parents → Account → *Delete account and all data*. This immediately and permanently deletes the account, progress, session history and recordings from the cloud and the device.
- Without the app, request deletion at [DELETE-ACCOUNT PAGE URL] or by email to [CONTACT EMAIL]; we delete the data within 30 days.

## Security

Data is sent over encrypted connections (HTTPS). Each account can only read and write its own data.
